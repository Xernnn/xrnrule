# Fonts

`res/font/misans_*.ttf` are MiSans Latin by Xiaomi, unchanged: the Regular, Medium, Demibold and
Semibold cuts and the variable one, which set the app's type (`ui/theme/Theme.kt`) and the block
screen's clock. This note sits here because `res/font/` may hold only fonts.

MiSans by Xiaomi, used under the MiSans font licence (free for commercial use when the software
notes that it uses MiSans). The font files are not covered by this repository's licence.
<https://hyperos.mi.com/font/en/>
